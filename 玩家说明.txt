========================================
  霓虹突袭  ·  NEON STRIKE   v0.50
========================================

【怎么玩】
  双击「NEON STRIKE.exe」即可。第一次启动要等十几秒（读模型资源，加载页有进度条）。

  主页面四个按钮：
    开始游戏 —— 竞技场，共 8 关，清空每关全部敌人即过关
    训练场   —— 无关卡、子弹无限，场上是 5 个随机兵种，清空后自动再刷一轮
    游戏教程 —— 操作方式、玩法说明、兵种图鉴
    游戏设置 —— 鼠标灵敏度 / 音量 / 全屏 / 阴影 / 画面风格

【按键】
  W A S D   移动
  鼠标      瞄准视角
  鼠标左键  射击（按住连发）
  鼠标右键  开镜 / 收镜（点一下切换）
  R         换弹
  F         检视枪械
  Shift     冲刺（可跑跳）
  空格      跳跃
  Esc       暂停菜单
  M         静音开关
  Alt       【仅训练场】呼出鼠标 → 用左上角菜单让敌人停/动、清空、按兵种添加；
            再按一次 Alt 回到游戏

【画面设置】
  每张地图的画面是**分开记**的：在竞技场调的画面只影响竞技场，训练场有自己的。
  设置会自动保存，下次打开仍然生效。

【存档】
  存档写在游戏目录下的 saves\ 文件夹里（跟 exe 同级）。
  想备份 / 换机器，直接拷这个文件夹即可。

【配置武器模型（可选，进阶）】
  models\models.json 可以调手上的枪：
    { "weapon": { "file": "qbz191.glb", "normalize": 1.05, ... } }
  把别的 .glb 放进 models\ 再把 file 改成它，就能换枪。

【闲话】
  这个游戏不商用，随便玩、随便传。用的是 MIT 的 three.js；
  武器模型由本项目工具从外部模型处理而来，署名见 web\models\CREDITS.txt。

【遇到问题】
  1) 双击没反应 / 闪退：确认 WebView2Loader.dll 和 exe 在同一个文件夹里。
     Windows 10/11 一般自带 WebView2 运行时；若没有，装一次
     「Microsoft Edge WebView2 Runtime」即可。
  2) 想全屏：设置里打开「全屏」。
  3) 想重新编译（一般不需要）：powershell -File tools\build-tauri.ps1
     注意：本文件夹名（含版本号）**尽量别改成中文名** —— 编译时 MinGW 的 dlltool
     处理不了非 ASCII 路径；万一改了，构建脚本会自动改用 %TEMP%\neon-player-ascii
     作为临时编译目录，编译完把 exe 拷回来。
     另外：改过文件夹名之后第一次编译前，先把 src-tauri\target 删掉
     （编译缓存里记着旧的绝对路径，不删会报 "系统找不到指定的路径"）。
